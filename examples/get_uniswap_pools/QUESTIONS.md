# Вопросы для создания адаптера вашей биржи

## 1. Factory контракт

### Методы для получения списка пулов:
- ✅ Есть ли метод `allPairsLength()` → возвращает `uint256` (количество пар)?
- ✅ Есть ли метод `allPairs(uint256 index)` → возвращает `address` (адрес пары по индексу)?
- ❓ Или используются другие методы/события для получения списка пулов?

### Создание пулов:
- ❓ Как создаются новые пулы? Есть ли событие `PairCreated(address token0, address token1, address pair, uint256)`?
- ❓ Или используется другой механизм (например, через отдельный метод)?

## 2. Кастомные Fee (комиссии)

### Где хранится fee для каждого пула?
- ❓ **Вариант A**: В Factory контракте (есть метод типа `getFee(address pair)` или `feeForPair(address pair)`)?
- ❓ **Вариант B**: В самом Pair контракте (есть метод `fee()` или `swapFee()`)?
- ❓ **Вариант C**: Fee передается при создании пула и хранится в Factory (можно получить через `pairFee(address pair)` или подобное)?
- ❓ **Вариант D**: Другое место?

### Формат fee:
- ❓ В каком формате хранится fee?
  - Например: `300` = 0.3% (как в Uniswap V3)
  - Или: `0.003` = 0.3% (как float)
  - Или: `3` = 3 базисных пункта (0.03%)
  - Или другой формат?

### Можно ли fee изменить после создания пула?
- ❓ Или fee фиксируется при создании и не меняется?

## 3. Pair контракт

### Стандартные методы Uniswap V2:
- ✅ Есть ли `token0()` → возвращает `address`?
- ✅ Есть ли `token1()` → возвращает `address`?
- ✅ Есть ли `getReserves()` → возвращает `(uint112 reserve0, uint112 reserve1, uint32 blockTimestampLast)`?

### События:
- ✅ Есть ли событие `Sync(uint112 reserve0, uint112 reserve1)`?
- ✅ Есть ли событие `Swap(...)`?

## 4. Дополнительные вопросы

### Название вашей биржи:
- ❓ Как называется ваша биржа? (для DexID и названия пакета)

### Специфичные методы:
- ❓ Есть ли какие-то дополнительные методы в Factory или Pair, которые нужно учитывать?

### ABI контрактов:
- ❓ Можете предоставить ABI для Factory и Pair контрактов? (JSON файлы)
